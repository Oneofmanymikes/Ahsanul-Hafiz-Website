Copying the form's code (plain text)

Click any of the .txt links in the table above. The file opens directly in your browser (or downloads, depending on your browser). Select all (Ctrl+A), copy (Ctrl+C), and paste into the host site's HTML editor — or save it as a .html file and host it yourself. The .txt and .html versions are byte-identical; the only difference is the extension, which tells the browser to show the code as text instead of rendering it.

Embed as iframe (recommended)

Paste this snippet into the host page wherever you want the form to appear. The form auto-reports its height to the parent page, so it'll resize to fit its content as the user interacts with it:

<iframe
  src="https://votehafiz.ca/forms/signup.html"
  title="Sign up for Hafiz campaign updates"
  loading="lazy"
  style="width:100%; border:0; min-height:380px;"
  id="hafiz-signup-frame"></iframe>

<script>
  // Auto-resize the iframe as the form's content changes.
  window.addEventListener('message', function(e) {
    if (e.data && typeof e.data.hafizFormHeight === 'number') {
      var f = document.getElementById('hafiz-signup-frame');
      if (f) f.style.height = (e.data.hafizFormHeight + 24) + 'px';
    }
  });
</script>

Replace signup.html with whichever form file you want. To embed several on one page, give each iframe a unique id and adjust the resizing script to target the right one.

How submissions work

  • Each form POSTs to the same Google Apps Script endpoint as the main campaign site.
  • Submissions appear in the Main Page tab of the campaign supporter Sheet.
  • Every visitor gets a session_id in their browser's localStorage so multiple form submits from the same person (e.g. signing up then donating) upsert into a single row rather than creating duplicates.
  • localStorage is scoped per-origin: a visitor filling out the form on partnerwebsite.com gets a different session_id than the same person on votehafiz.ca. That's intentional — each embed source can be tracked separately.

Styling

Forms are styled with Ontario Liberal Party brand colours (cardinal red, deep maple). The card has a transparent body background so the host page's background shows through outside the form's white card. To change anything, edit the <style> block at the top of each HTML file.
